# 24-Week Roadmap (CCNA 200-301 based)

Time: roz 2-3 ghante (1h theory/video, 1h lab, 30m revision/quiz).
Har week ke end par: mini quiz (AI se) + 1 lab complete.

## Phase 1 – Foundations (Week 1-4)
**Week 1: Networking kya hai**
- LAN/WAN/Internet, client-server, ISP, devices (router, switch, AP, firewall)
- OSI vs TCP/IP model (7 layers), data encapsulation
- Lab: Packet Tracer install, 2 PCs + switch connect karo, ping karo

**Week 2: IP addressing**
- Binary, decimal conversion, IPv4 classes, public vs private, subnet mask
- Lab: PCs ko manual IPs do, ping test

**Week 3: Subnetting (sabse zaroori)**
- CIDR, /24 /25 /26..., network/broadcast/host range, VLSM
- Roz 20 subnetting questions (subnettingpractice.com)
- Lab: ek company ke 4 departments ke liye subnet design

**Week 4: Ethernet & Switching basics**
- MAC address, ARP, switch MAC table, collision/broadcast domain, cables
- Cisco IOS CLI basics (enable, conf t, show commands)
- Lab: switch configure karo (hostname, password, banner)

## Phase 2 – Switching (Week 5-8)
- Week 5: VLANs, access ports, trunking 802.1Q
- Week 6: Inter-VLAN routing (router-on-a-stick)
- Week 7: STP (Spanning Tree), EtherChannel
- Week 8: Port security, DHCP snooping basics + **Revision + mock test 1**

## Phase 3 – Routing (Week 9-14)
- Week 9: Router basics, routing table, static routes, default route
- Week 10: Dynamic routing concepts, OSPF single area
- Week 11: OSPF multi-area basics, neighbor troubleshooting
- Week 12: DHCP, DNS, NAT/PAT
- Week 13: First Hop Redundancy (HSRP concept), IPv6 basics
- Week 14: **Revision + mock test 2** + mini project 1 (company network)

## Phase 4 – Services & Security (Week 15-19)
- Week 15: ACLs (standard/extended)
- Week 16: Network security: firewalls, VPN (IPsec, site-to-site), AAA, port security
- Week 17: Wireless (WLAN, SSID, WPA2/3, controllers)
- Week 18: SNMP, Syslog, NTP, QoS basics, SSH
- Week 19: WAN, Cloud basics (AWS VPC, subnets, security groups)

## Phase 5 – Automation + Your Edge (Week 20-22)
- Week 20: Python basics for network (netmiko, paramiko)
- Week 21: REST APIs, JSON, Ansible basics, SDN concepts
- Week 22: Wireshark packet analysis, troubleshooting method

## Phase 6 – Exam & Career (Week 23-24)
- Week 23: Full mock exams (Boson ExSim, Jeremy's IT Lab), weak topics repeat
- Week 24: CCNA exam book karo, CV/LinkedIn update, applications

## Mini Projects (portfolio ke liye)
1. Small office network (VLAN + DHCP + inter-VLAN)
2. Multi-branch company (OSPF + NAT + ACL + VPN)
3. Automation: Python script jo 5 switches par config push kare
4. AWS VPC with public/private subnets (cloud networking)
